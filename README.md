# Лабораторна робота №2
### Профілювання продуктивності, оптимізація C++ та оцінювання енергоспоживання

**Мета:** дослідити вплив компіляторних оптимізацій на продуктивність та енергоспоживання програми C++ за допомогою GNU time, perf, FlameGraph та аналізу асемблерного коду.

### Середовище
- **Процесор:** Intel Pentium Silver N6000
- **ОС:** Ubuntu (WSL2) / Windows
- **Інструменти:** GCC, perf, GNU time, objdump, FlameGraph, Compiler Explorer, PowerShell, Windows SRUM

### Компіляція та запуск

```bash
g++ -O0 -g -fno-omit-frame-pointer main.cpp -o program_O0
g++ -O3 -march=native -g -fno-omit-frame-pointer main.cpp -o program_O3
g++ -O3 -march=native -ffast-math -g -fno-omit-frame-pointer main.cpp -o program_fast

./program_O0 300
./program_O3 300
./program_fast 300
```

Програма обробляє масив із 1 000 000 чисел `double`, обчислюючи квадратні корені та суму результатів.

### Основні результати

| Показник | Результат |
|---|---|
| Середній час `-O0` | 4,802 с |
| Середній час `-O3` | 1,908 с |
| Прискорення | **2,52 раза** |
| Зменшення кількості інструкцій | 89,5% |
| Зменшення системних енерговитрат | 65,4% |
| Орієнтовне зменшення додаткових енерговитрат програми | 37% |

Після оптимізації `-O3` компілятор вбудував `processArray` у `main` та усунув зайві виклики. Додатково підтверджено SSE2-векторизацію з `-ffast-math`. AVX2 продемонстровано окремо в Compiler Explorer через обмеження процесора.

Оцінки енерговитрат програми є наближеними, оскільки отримані шляхом віднімання фонового споживання системи.
